# Physical Social Games

A reusable set of wearable ESP32-C3 game controls, a local hub, and a library of physical social games.

## Repository structure

| Folder | Contents |
|---|---|
| [`presentations/`](presentations/) | English and Arabic PowerPoint explainers |
| [`manuals/`](manuals/) | The 24 source manuals, compiled handbook, and expansion pack |
| [`hardware/`](hardware/) | PCB and enclosure design files |
| [`firmware/`](firmware/) | Wearable-node and hub firmware |
| [`software/`](software/) | Host web app, backend, and shared game logic |
| [`assets/`](assets/) | Images used by the manuals and presentations |
| [`tools/`](tools/) | Scripts that build, export, and verify project documents |

## Current status

The repository currently contains the complete product documentation, visual assets, compiled manuals, and game presentations. The PCB, enclosure, firmware, and host-application folders are ready for implementation files as development begins.
