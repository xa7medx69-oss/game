# Software

Host-side product code belongs here.

Recommended layout:

- `web-app/` — local browser interface served by the hub.
- `game-engine/` — reusable game rules and state machines.
- `backend/` — optional online services added after the offline MVP.
- `shared/` — schemas, types, and shared utilities.

See manuals 07–11 under [`manuals/chapters`](../manuals/chapters/).
