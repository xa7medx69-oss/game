# Hardware

Product hardware files belong here.

- [`pcb/`](pcb/) — schematics, PCB layouts, Gerbers, drill files, BOMs, and pick-and-place files.
- [`enclosure/`](enclosure/) — CAD, STL/STEP files, drawings, and assembly notes.
- [`3d-print/`](3d-print/) — print-ready prototype models, parametric generators, and build instructions.

The current design guidance is documented in manuals 02–05 and 12–15 under [`manuals/chapters`](../manuals/chapters/).
