# Changelog

## V1 — 2026-08-23

- Created a 62 mm parametric wearable enclosure.
- Selected four heat-set inserts and screws for repeatable service access.
- Added tongue-and-groove alignment and a TPU compression gasket.
- Added a captured cap, TPU button diaphragm, and translucent light ring.
- Added a removable side-by-side battery/XIAO electronics carrier.

## Required physical-test feedback for V2

- Actual battery, connector, antenna, switch, LED, motor, and buzzer dimensions.
- Printer/material shrink and insert-hole selection from the coupon.
- Measured button force, travel, edge-press consistency, and false activation.
- Worn radio performance and best antenna position.
- Strap comfort, abnormal-load release, and clip/strap preference.
- Drop, sweat-wipe, heat, repeated opening, and charging-test results.
