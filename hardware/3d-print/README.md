# 3D-Printable Hardware

## Current model

- [`wearable-pod-v1/`](wearable-pod-v1/) — serviceable 62 mm wearable game-button enclosure.

Every model folder should contain editable parametric source, print-ready STL files, a BOM, print settings, assembly instructions, validation notes, and a revision history.

These are prototype files. A successful slice or print does not prove electrical, battery, impact, skin-contact, ingress, or child-product safety.
